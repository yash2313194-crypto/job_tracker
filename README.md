# Job Tracker

A full-stack job portal application with a separate frontend and backend.



## Features
- User registration and login
- Browse, create, update and delete jobs
- Apply to jobs
  

## Tech Stack
- Backend: Node.js, Express.js, MongoDB
- Frontend: React

## How to Run

**Backend**
```bash
cd backend
npm install
npm start
```


**Frontend**
```bash
cd frontend
npm install
npm run dev
```
